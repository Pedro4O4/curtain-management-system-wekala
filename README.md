# El-Wekala Curtains

Full-stack starter for the El-Wekala Curtains website using Next.js, NestJS, and MongoDB.

## Environment

Copy `.env.example` to `.env` and fill in your MongoDB Atlas connection string.

## Structure

- `frontend` - Next.js frontend
- `backend` - NestJS backend connected to MongoDB

## Scripts

- `npm run dev` - run frontend and backend together
- `npm run build` - build both apps
- `npm run lint` - lint both apps
